Åtta löpargrupper du vill springa med i veckan!

Skotest med Salomon och Saucony, gravid- och postpartumlöpning med Nasci, och sen pekar hela veckan mot lördagen, Stockholm Halvmaraton. RTC, ON Run Club och nykomlingen Kutar Run Club bjuder alla in till shakeout-rundor de sista dagarna innan startskottet.

25–28 augusti 2026 Stockholm 8 events

Jag på Stockholms stadion, samma bana där RTC kör sin Half Marathon Sharpener på torsdag, två dagar innan Stockholm Halvmaraton.

Utöver löpareventen nedan finns det en rad andra pass att haka på. Som vanligt springer grupper som Stockholm Run Club och Triple Threshold RC, och lördagen tillhör förstås Stockholm Halvmaraton.

Salomon + Solemates

Runda runt Djurgården med frukost och skotest, ett fint sätt att starta tisdagen.

Solemates drar igång tisdagen med en runda runt vackra Djurgården, i sällskap med Salomon. Lagom tills jobbet eller skolan startar har du hunnit springa, äta frukost och hänga med sköna människor, och på vägen kan du testa Salomons skor.

Nasci Run Club

Löpgrupp för gravida och postpartum, träningen sker på dina villkor.

Nasci Run Club är en supermysig grupp för dig som är gravid eller har fått barn, där träningen anpassas efter din kropp och dina behov. Förutom löpningen är det en perfekt plats att dela erfarenheter på och komma tillbaka till löpningen tillsammans med andra. Ett begränsat antal barnvagnar finns att låna på plats.

Saucony Run Club

Lugn frukostrunda i tre fartgrupper, med chans att testa nya skor på vägen.

Shakeout run i två fartgrupper, dagen innan Stockholm Halvmaraton.

Mile Makers Run Club

Kontrollerad distans i lugnt tempo, en skön nedvarvning inför helgens lopp.
