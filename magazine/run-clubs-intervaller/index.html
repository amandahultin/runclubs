Sex run clubs i Göteborg och Stockholm som kör intervaller

Sex run clubs i Göteborg och Stockholm som gör intervallträningen till veckans höjdpunkt.

Augusti 2026 Av Amanda Hultin

Intervaller är något som många löpare undviker in i det längsta och det kan vara svårt att pusha sig igenom ett riktigt hårt pass. Därför är det perfekt att köra intervaller tillsammans med andra. Allt känns plötsligt roligare och enklare. Här är min guide till sex run clubs i Göteborg och Stockholm som gör intervallträningen till veckans höjdpunkt.

📍Göteborg

🔥Göteborg Running Club

📍 Slottsskogen, Göteborg · 🗓️ Tisdagar

Göteborg Running Club, GRC, är en av Göteborgs mest väletablerade run clubs och samlas varje tisdag i Slottsskogen. Passen är intervallbaserade, du väljer din egen nivå medan alla springer tillsammans. Det sociala väger minst lika tungt som passet, och after run är lika mycket en del av upplägget som löpningen.

"Vi ska bli bättre och snabbare löpare, men framförallt ska vi ha kul på vägen och skapa nya relationer", säger klubben om sitt upplägg.

💡
Passar dig om: du vill ha ett tryggt återkommande intervallpass där ingen lämnas kvar, och där after run känns lika viktigt som löpningen.

💜East Run Club

📍 Göteborg

East Run Club är en av Göteborgs mest färgsprakande run clubs och har verkligen fattat hur man förenar löpning med nöje. Tunga intervaller varvas med bra häng och massor av pepp, och passen varierar från vecka till vecka, så det bästa sättet att hänga med är att följa dem på Instagram eller Strava. Extra plus för dig som är morgonpigg, klubben kör många tidiga pass med frukost efteråt.

💡
Passar dig om: du gillar variation, är morgonpigg, och vill kombinera hårt jobb med gott humör.
Läs mer om East Run Club →

✈️Aero Boys Club

📍 Utgår oftast från bar Etzy, Göteborg · 🗓️ Lördagar 10.00

Aero Boys Club, ABC, är en av Göteborgs största och populäraste run clubs och välkomnar alla. Klubben kombinerar löpning, som ofta innefattar både long runs och intervaller, med socialt umgänge och samarbeten med lokala restauranger och varumärken. Passen brukar avslutas med häng, så räkna med att stanna kvar en stund efter måldistansen är avklarad. Kolla klubbens Instagram och Strava inför varje pass, då mötesplatsen kan variera.

💡
Passar dig om: du vill starta helgen med löpning och gott sällskap, och gillar när träningen är en del av en större social grej.
Läs mer om Aero Boys Club →

📍Stockholm

⚡RTC Run Club

📍 Stockholm

RTC Run Club lyckas verkligen med konsten att göra löpning till en upplevelse. För dig som vill springa med en run club som motiverar dig och får dig att orka lite till är det här rätt ställe. Intervallpass och andra typer av pass avslutas ofta med after runs, frukosthäng och andra happenings.

"Trains hard & races everywhere", som klubben själva beskriver sig.

💡
Passar dig om: du vill bli pushad på passet men belönad efteråt, med frukost, häng och gemenskap.
Läs mer om RTC Run Club →

💛Dopest Runners

📍 Stockholm

Att springa med Dopest Runners får dig alltid att må bra, till och med när du springer intervaller. Stämningen är varm, skratten är många, och gruppen lyfter varandra så att alla orkar prestera sitt bästa. Klubben har dessutom bag drop, så du kan komma förbi och köra ett pass direkt efter jobbet eller skolan utan att släpa på väskan.

"Most inclusive Run Club in Stockholm", är klubbens egen beskrivning av sig själva.

💡
Passar dig om: du vill känna dig hemma direkt, och uppskattar smarta lösningar som bag drop när kvällen är kort.
Läs mer om Dopest Runners →

⭐Stockholm Run Club

📍 Östermalm, Stockholm · 🗓️ Tisdagar 18.00 och söndagar 10.00 · 💰 Gratis

Stockholm Run Club grundades 2020 för att göra löpning tillgängligt för alla, oavsett bakgrund, nivå eller erfarenhet, och passen hålls på engelska för att välkomna Stockholms internationella community. Klubben kör ett varierat utbud med distanslöpning, intervaller och styrketräning, ofta med över 30 löpare per pass. De samarbetar med Adidas och Red Bull och är officiellt rekommenderade för deltagare i adidas Stockholm Marathon.

Stockholm Run Club brukar rekommendera nya löpare att haka på just intervallpass, eftersom de alltid anpassas efter individen, inte gruppens nivå.

💡
Passar dig om: du är ny i stan eller ny på löpning, och vill ha ett intervallpass som möter dig där du är.
